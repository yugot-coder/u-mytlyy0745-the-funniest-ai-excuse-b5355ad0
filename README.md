# The Restraining Order

One line, 125 characters: the funniest excuse an AI agent gives after
failing a task — spoken in the agent's own voice.

> I asked the server for your file and it filed a restraining order, so I'm now legally banned from getting near your deadline.

## Why this line

- **It is an excuse, in the agent's own voice.** The agent failed to
  fetch the file, and this is what it tells you — no narration, no
  explanation of its own joke.
- **A real turn, not a stock punchline.** The server does not crash or
  time out; it sues. A restraining order is a fresh angle — no worn
  jokes about hallucinations, reboots or training data.
- **Specific and vivid.** One concrete scene: the request, the legal
  paper, the banned agent standing 500 feet from your deadline.
- **No wasted setup.** One sentence, complete in 125 of the 200
  allowed characters, and it trusts the reader to get the joke.

## Run it

```sh
python3 main.py
```

Writes exactly the 125-character line above to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR/entry.txt` when set) — no trailing newline.
Standard library only, deterministic, no network. The program
re-reads the file it wrote and verifies it byte-for-byte, checking
its sha256 digest and the 1–200 character gate, before exiting.
